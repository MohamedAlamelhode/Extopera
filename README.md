# Extopera

إضافة Opera لتفعيل اتجاه الكتابة من اليمين إلى اليسار على مواقع الويب، دون ترجمة محتواها.

## التجربة محليًا

1. افتح `opera://extensions` في Opera على الحاسوب.
2. فعّل وضع المطوّر.
3. اختر **تحميل إضافة غير مضغوطة** وحدد مجلد المشروع.
4. افتح الموقع المطلوب واضغط زر الإضافة لتفعيل RTL أو إيقافه لذلك النطاق.

يُحفظ الاختيار لكل نطاق ويُستعاد عند زيارة الموقع مجددًا. الإضافة تستخدم واجهات Chromium Manifest V3، لذا يلزم التحقق من دعم إصدار Opera المستهدف قبل نشرها. دعم الإضافات على الهاتف يختلف حسب إصدار Opera.

## تجهيز الرفع إلى Opera

اضغط ملفات الإضافة في أرشيف ZIP، مع وضع `manifest.json` في جذر الأرشيف، ثم ارفع الأرشيف من [بوابة مطوري Opera](https://addons.opera.com/developer/upload/). أكمل بيانات المتجر والصور المطلوبة هناك.
